Brick Workshop 5.9.13

Android · offline · EN / PT / ES

Independent mod tool for your own copy of the supported block game on Android: characters (including 19 hidden ones from the game), texts, textures, weapons, levels and a block map builder, plus an experimental PC mod converter. No internet, no ads, no data collection.

Download APK

Requirements

  • Android 8.0+, 64-bit (arm64) device
  • The supported game (version 2.0 for Android) installed; the Game tab tells you if it works (the app does not include game files)
  • About 2 GB free

Install

  1. Download the APK.
  2. Allow "install unknown apps" for your browser or file manager. On devices with Android developer verification you may see an "unregistered developer" warning.
  3. Open the app and follow the Game tab.
  4. Back up the game key: Settings → Save a copy of the key.
